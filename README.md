# UNO風カードゲーム — CPU対戦

ブラウザだけで遊べる UNO 風カードゲーム(CPU対戦)。単一HTMLファイルで動作し、インストール不要です。

## 遊び方

https://tarepon.github.io/uno/ を開くだけ。CPUと対戦できます。

## おまけ: スーパーカートグランプリ

疑似3D(Mode 7風)のカートレースゲームも遊べます: https://tarepon.github.io/uno/kart.html

- 6キャラクターから選んで、AIライバル5台と3周レース
- ドリフト&ミニターボ、アイテム(キノコ・こうら・バナナ)、コイン、ブーストパッド
- 操作: ↑↓←→/WASD で走行、スペースでホップ&ドリフト、Shift/E でアイテム、M でミュート
- スマホはタッチ操作対応(オートアクセル)

## 技術

HTML + CSS + Vanilla JavaScript(依存ライブラリなし・単一ファイル)
